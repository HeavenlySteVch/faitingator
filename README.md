# WoW Damage Parser

Приложение читает боевой журнал World of Warcraft (`WoWCombatLog.txt`) и разбивает его
на **заходы в подземелья**. Виден список заходов, а по клику на строку — детали:
состав группы, класс и характеристики каждого игрока, урон, исцеление, прерывания,
смерти и разбивка по способностям.

## Быстрый старт

1. **Включи запись боевого журнала** — один раз в игре в чат:
   ```
   /combatlog
   ```

2. **Включи расширенное логирование** (нужно для классов и характеристик):
   ```
   /console advancedCombatLogging 1
   ```
   Без него лог работает, но остаются только урон, исцеление, прерывания и смерти —
   события `COMBATANT_INFO` не пишутся. Если галочки не хватает, попробуй ещё и
   `Улучшить логирование боёв` в Настройки → Система → Сеть.

3. **Пройди подземелье** (ключ, обычный инст, рейд).

4. **Запусти приложение**: двойной щелчок по `Запуск.bat` или `python wow_damage_app.py`.
   Путь к журналу подставляется сам:
   ```
   C:\Firestorm\Battle for Azeroth Reforged\Logs\WoWCombatLog.txt
   ```
   (кнопка **«Обзор»** — если путь другой; приложение обновляется по F5).

## Как выглядит интерфейс

Сверху — таблица **заходов**, снизу — вкладки деталей выбранного захода.

### Вкладка «Заходы»

| Колонка | Значение |
|---|---|
| Дата | Дата и время начала захода |
| Подземелье | Название зоны |
| Ключ | Уровень кейса (`+10`) |
| Результат | `+1` / `+2` / `+3` / `провал` — на сколько плюсов закрыли |
| Время | Длительность прохождения |
| Таймер | Лимит времени подземелья |
| Группа | Размер группы |
| Урон группы | Суммарный урон всех участников |

Фильтр «Только ключи» оставляет только мифик+, строка поиска ищет по названию.

### Вкладка «Группа»

Кто был в группе, класс и специализация, урон, ДПС, доля от общего урона,
исцеление, число прерываний кастов и смертей.

### Вкладка «Характеристики»

iLvl, сила, ловкость, выносливость, интеллект, броня, крит, скорость, искусность
и универсальность — из события `COMBATANT_INFO` (поэтому требуется шаг 2 выше).
Значения выводятся теми же цветами, что и классы в игре.

### Вкладка «Способности»

Выбери игрока из списка — увидишь разбивку его урона по способностям:
урон, доля, число ударов, критов и самый сильный удар.

### Вкладка «Инфо»

Напоминание обо всех пунктах выше.

## Экспорт

- **Экспорт в Excel** — 4 листа: «Заходы», «Группа», «Характеристики», «Способности».
- **Экспорт заходов в CSV** — компактная таблица заходов (Excel открывает, разделитель `;`).

## Резервное копирование

По умолчанию изменения сохраняются с каждым изменением файлов. Если нужен отдельный заход —
скопируйте соответствующие файлы `requirement.md`, `design.md`, `tasks.md` в отдельную
папку (например, `docs/<имя-фичи>/`).

## Структура проекта

## Тестовые данные

```bash
python tools/make_sample_log.py

python tools\check_gui.py
```

## Если что-то не работает

- **«Файл не найден»** — журнал ещё не создан. Введи `/combatlog` в игре и пройди подземелье.
- **«Характеристики недоступны»** — не включено расширенное логирование.
- **Урон = 0** — скорее всего зона не подземелье (город/аэродром). Ищи нужный заход
  в списке или введи часть названия в поле поиска.
- **Бонус = «—»** — таймер для этого подземелья неизвестен. Таймеры прописаны в
  `classes.py` (словарь `DUNGEON_TIMERS`), можно добавить своё подземелье.
