# WoW Damage Parser

Приложение читает боевой журнал World of Warcraft (`WoWCombatLog.txt`) и показывает,
сколько урона ты нанёс в каждом заходе в подземелье: суммарный урон, DPS, долю от группы
и разбивку по способностям.

## Быстрый старт

1. **Включи боевой журнал в игре.** Один раз введи в чат:
   ```
   /combatlog
   ```
   В ответ придёт сообщение, что запись журнала включена. Команда сохраняется между сессиями,
   но проверять её стоит после больших обновлений клиента.

2. **Пройди подземелье** (ключ, рейд, обычный инст) как обычно.

3. **Запусти приложение:**
   - двойным щелчком по `Запуск.bat`, или
   - из консоли: `python wow_damage_app.py`

4. Нажми **«Загрузить»**. Приложение найдёт файл журнала по стандартному пути:
   ```
   C:\Firestorm\Battle for Azeroth Reforged\Logs\WoWCombatLog.txt
   ```
   Если путь другой — кнопка **«Обзор»**.

5. В таблице **«Заходы»** появится список подземелий. Выбери заход — во вкладке
   **«Способности»** увидишь разбивку урона по способностям.

## Что показывается

| Колонка | Значение |
|---|---|
| Зона | Название подземелья/локации |
| Начало | Дата и время начала захода |
| Длительность | От первого до последнего удара в зоне |
| Урон | Суммарный урон, нанесённый тобой (+ питомцы) |
| DPS | Урон, делённый на активное время |
| Доля группы | Твой урон относительно всей группы за заход |
| Активное время | Число секунд, в которые ты реально бил |

## Важные детали

- Файл журнала можно читать, **пока игра запущена** — данные допишутся при следующей загрузке.
- Журнал растёт со временем. Если он станет очень большим (гигабайты) — старые записи можно
  удалить, приложение работает построчно и не требует много памяти.
- Поддерживаются **оба формата** журнала: обычный и расширенный (`Advanced Combat Logging`).
  Расширенный даёт точные криты и корректный учёт питомцев.
- Питомцы и тотемы учитываются, если включена соответствующая галочка.
- Экспорт: CSV (Excel-совместимый, разделитель `;`) и XLSX.

## Консольный режим

```bash
python wow_damage_app.py --cli "путь\к\WoWCombatLog.txt"
python wow_damage_app.py --cli "путь\к\WoWCombatLog.txt" --player Awdawdas
python wow_damage_app.py --cli "путь\к\WoWCombatLog.txt" --no-pets
```


## Если что-то не работает

- **«Файл не найден»** — журнал ещё не создан. Введи `/combatlog` в игре и пройди подземелье.
- **Урон = 0** — скорее всего в списке выбран не тот персонаж. Выбери себя в выпадающем списке.
- **Не видно заходов** — в журнале нет события смены зоны (`ZONE_CHANGE`). Обычно оно появляется
  при входе в подземелье; попробуй перезайти в инст.
